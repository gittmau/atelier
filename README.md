# Shine Silk — novo design

Versão estática pronta para GitHub Pages, com a identidade Shine Silk refinada e a cor dourada `#D1AF67` incorporada como cor de assinatura.

## Arquivos
- `index.html` — estrutura e conteúdo.
- `style.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, animações de entrada, botão voltar ao topo e ano automático.


O layout não depende de Bootstrap, React ou outra biblioteca de interface.

### Paleta principal
- Vinho: `#8d5264`
- Vinho escuro: `#623744`
- Dourado Shine Silk: `#D1AF67`
- Creme: `#fbf6f1`
