# Shine Silk — novo design

Versão estática pronta para GitHub Pages, com a identidade Shine Silk refinada e a cor dourada `#D1AF67` incorporada como cor de assinatura.

## Arquivos
- `index.html` — estrutura e conteúdo.
- `style.css` — identidade visual, responsividade e animações.
- `script.js` — menu mobile, animações de entrada, botão voltar ao topo e ano automático.

## Publicação
Substitua os arquivos do repositório atual pelos três arquivos deste pacote e mantenha `index.html` na raiz.

### Antes de publicar
1. Troque o número do WhatsApp no link `https://wa.me/5500000000000`.
2. Troque `contato@shinesilk.com.br` pelo e-mail real.
3. Substitua os links `#` do Instagram/Facebook pelos perfis reais.
4. Se quiser hospedar as imagens localmente, baixe as fotos usadas e altere os `src`/backgrounds para arquivos da pasta do projeto.

O layout não depende de Bootstrap, React ou outra biblioteca de interface.
